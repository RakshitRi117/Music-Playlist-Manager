This project demonstrates the practical application of the linked list data structure in real-life scenarios, such as managing a music playlist. Users can add songs to the end of the playlist, delete songs, navigate to the next track, and perform various other operations. The program utilizes a menu-driven interface, allowing users to select desired actions and interact with the playlist efficiently through linked list functionalities.
## Features
- Add songs to playlist
- Display all songs
- Play current song
- Skip to next song
- Remove songs

## How to Run
1. Compile: g++ playlist.cpp -o playlist
2. Run: ./playlist
